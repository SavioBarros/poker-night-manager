# Poker Night Manager 🃏

Aplicativo PWA de gerenciamento de noites de poker entre amigos.

**Funcionalidades:**
- 🎯 Mesa principal com jogadores, buy-ins e rebuys
- 🤝 Calculadora de acerto de contas ("Quem deve pra quem?")
- 🏆 Ranking acumulado com pódio
- 📜 Histórico de sessões
- 📲 Compartilhamento via WhatsApp
- 🎨 3 temas visuais (Emerald, Royal, High Roller)
- ↕️ Drag & Drop para reordenar jogadores
- 📳 Haptic Feedback para interações no celular

**Tecnologias:** HTML5, CSS3, JavaScript Vanilla, PWA (Service Worker)
